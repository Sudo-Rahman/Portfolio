# Fiches projets

Une fiche par projet du portfolio, affichée sur la page `/projects/<slug>` du site. Le nom du fichier doit correspondre au `slug` du projet dans `src/lib/data/projects.ts`.

Chaque fiche suit la même trame : une introduction, « En bref », les liens, le besoin ou le sujet, ce que fait le projet, comment il est construit, ses limites et ce qu'il montre. Le premier titre (`#`) n'est pas affiché : la page reprend déjà le nom du projet.
