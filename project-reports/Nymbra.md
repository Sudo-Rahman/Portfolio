- **Application iPhone** disponible sur l'App Store, dans la categorie utilitaires.
- **Coffre-fort prive chiffre** pour documents, photos, videos, scans, archives et enregistrements audio.
- **Protection d'acces** par Face ID ou Touch ID, avec verrouillage automatique.
- **Organisation par type de fichier** : documents, images, videos, audio, archives et autres fichiers.
- **Synchronisation iCloud optionnelle** pour retrouver le coffre sur ses appareils Apple.

## Objectif

Nymbra repond a un besoin simple : garder des fichiers sensibles a portee de main sur iPhone sans les melanger aux dossiers, albums et applications du quotidien. L'application cree une copie protegee dans son coffre-fort, puis permet de retrouver, previsualiser, favoriser et exporter les elements lorsque c'est necessaire.

Le produit cible les documents personnels, justificatifs, recus, notes confidentielles, medias prives et fichiers que l'utilisateur veut isoler dans un espace plus controle.

## Fonctionnalites principales

### Import et capture

- Ajout de documents, images, videos, scans, archives et fichiers audio.
- Import depuis les emplacements iOS habituels.
- Extension de partage pour envoyer des fichiers compatibles vers Nymbra depuis d'autres apps.
- Conservation des fichiers sources : supprimer une copie dans Nymbra ne supprime pas le fichier original.

### Organisation et recherche

- Classement automatique par type de fichier.
- Recherche dans le coffre-fort.
- Apercu rapide sans sortir du flux principal.
- Favoris pour retrouver les elements importants plus vite.

### Securite et confidentialite

- Ouverture protegee par Face ID ou Touch ID.
- Verrouillage automatique configurable.
- Stockage local par defaut.
- Synchronisation iCloud optionnelle : lorsque l'utilisateur l'active, les fichiers chiffres et les metadonnees du coffre sont stockes dans iCloud pour ses appareils.
- Pas de compte serveur Nymbra pour le contenu du coffre.

L'interface reste volontairement compacte : l'accueil donne un apercu du coffre, les types de fichiers structurent la navigation, et les actions principales restent proches du contenu. ## Choix de presentation dans le portfolio

Contrairement aux projets open source du portfolio, cette fiche ne contient pas d'extraits de code, de structure de depot, de fichiers internes ni de details d'implementation non publics. Elle presente uniquement :
